# Portfolio Risk Analyzer

Monte Carlo VaR simulation, efficient frontier optimization, and portfolio risk analytics.

## Quick Start

Backend:
- cd backend
- python -m venv venv
- source venv/bin/activate
- pip install -r requirements.txt
- uvicorn app.main:app --reload

Frontend (new terminal):
- cd frontend
- npm install
- npm run dev

Open http://localhost:5173
